# 考公产品需求深度拆解与边缘场景

## 一、 核心边缘场景 & 逻辑断层
1. **“买课打卡反学费”的风控与财务场景**：作弊判定（防挂机刷时间）、退费路径（原路退回的手续费成本）、中断处理（请假补签卡）、财务合规。
2. **UGC 的合规与审核**：内容合规（敏感词过滤机制）、前端举报通道。
3. **多端账户同步与体系**：账号互通（微信小程序 UnionID 与 网页端手机号绑定）、多设备互踢（防止多人共享拼团一个账号）。
4. **AI 与 Token 计费模型**：AI 追问功能的 Token 成本把控、普通用户与VIP的消耗上限、生成过程中的加载等待态设计。
5. **异常状态与空数据**：新注册用户没有任何做题数据时的引导状态（Empty State）、断网状态提示。

## 二、 完整业务模块清单
1. **账号与基础系统**：注册登录、个人资料与考公目标设定、消息通知中心。
2. **题库与学习模块**：多模态题库展示引擎、正向计时器、单题防中断保存、名师解析对比系统、智能错题本。
3. **数据与激励模块**：学习热力图看板、细分能力雷达图、社交化备考周报。
4. **社群与攻略模块**：打卡契约群、内容发布瀑布流、互动评论体系、防骚扰黑名单。
5. **商业化与交易模块**：VIP购买收银台、支付系统接入、打卡零钱钱包、AI追问点数充值。
6. **运营与后台 (CMS)**：题库编辑（包含 OCR 多模态处理）、大模型 API 配置与监控、内容人工审核池、财务订单对账。
