# 全平台详细 Sitemap 与页面流转蓝图 (C端 + 管理后台)

基于多角色推演，为了确保前后端开发在同一套逻辑语境下工作，整理了这份极度详细的全站 Sitemap（页面树状结构）。

---

## 📱 第一部分：C端 (备考用户 App/小程序)

采用经典的移动端 `Bottom Tab Navigation` 布局。

### 🔘 Tab 1: 首页与学习 (Home & Practice)
**核心作用：用户最高频的刷题区与名师解析体验区。**

- **[一级页面] 学习主页 (`/`)**
  - **内容功能要求**: 
    - 针对新用户提供“5分钟摸底测试”卡片。
    - 顶部动态推荐“今日必须完成的任务”。
    - 中部放置题库分类的金刚区，及“错题本”入口。
  - **跳转逻辑**: 点击具体类目跳转至「题库列表页」；点击继续学习跳转至「刷题详情页」。

- **[二级页面] 题库分类列表页 (`/category`)**
  - **内容功能要求**: 
    - **极度细化的知识树**：不仅区分粗粒度题型（如图形推理），更深度细化到子类（如空间重构、数量类等）。
    - **名师技巧筛选体系**：除了按题型分类，用户还可通过“特定名师做题方法/技巧”（如：“老王的代入排除法应用题目”）进行专门的归类刷题。
  - **跳转逻辑**: 点击末级知识点或特定技巧分类进入「刷题详情页」。

- **[二级页面] 刷题详情页 (`/practice`) —— 核心体验点**
  - **内容功能要求**: 
    - 完整无损展示包含图表/图片的题干文本（多模态支持）。
    - **顶部正向计时器**：不再使用倒计时制造焦虑，而是通过正向计时精准记录用户的思考时间。
    - **单题防中断机制**：答题动作在前端即时缓存，断网也能保存当前选项。
  - **弹窗与交互**: 
    - `[底部弹窗] 答题卡抽屉`：点击展开全卷网格。
    - `[确认弹窗] 提前交卷确认`。
  - **跳转逻辑**: 主动交卷后，流转至「题目解析页」。

- **[二级页面] 多维解析与 AI 互动页 (`/analysis`) —— 核心付费点**
  - **内容功能要求**: 
    - **名师流派 Tab 切换**：平行展示 A老师、B老师、AI。
    - **AI 苏格拉底追问框**：允许用户就解析继续提问。
  - **弹窗与交互**:
    - `[提示弹窗] 余额不足提示`：追问消耗点数，不足时弹出充值。

### 🔘 Tab 2: 学习数据看板 (Dashboard)
- **[一级页面] 学习数据主页 (`/dashboard`)**
  - **内容功能要求**: 热力图、细化的技巧掌握度雷达图。

### 🔘 Tab 3: 督学社群 (Community)
- **[一级页面] 社群与攻略大厅 (`/community`)**
- **[二级页面] 契约督学群详情 (`/pledge-detail`)**
- **[二级页面] 帖子详情与互动页 (`/post`)**

### 🔘 Tab 4: 个人中心与商业化 (Profile)
- **[一级页面] 我的主页 (`/profile`)**
- **[二级页面] 钱包与充值中心 (`/wallet`)**

## 💻 第二部分：B端 (平台管理员 / 运营后台)

### 🛠️ 侧栏 1: 题库与大模型资产 (核心工作流)
- **[页面] 题库列表与编辑大厅**
  - **功能要求**: 
    - **全局编辑权限**：无论题目处于识别阶段还是已经存入数据库后，管理员随时可以点击进行全方位的编辑修改（包括修改错别字、重新裁剪图片、替换选项）。
- **[弹窗] 多模态 OCR 导题工作台**
  - **功能要求**: 支持拖拽上传 PDF。自动框选裁剪题干中的几何图/统计表并保存为独立图片链接，保证原汁原味。
- **[页面] AI 接口配置与模型嗅探中心 (Wow 级管理)**
  - **功能要求**: 
    - 表单输入：Base URL 与 API Token。点击自动嗅探支持的模型并多选。
    - **Teacher Skill 配置池**：支持手动编写名师设定。**新增【外部导入机制】**，允许从 GitHub 或指定 URL 一键导入 Prompt 配置文件；导入后页面带有【更新按钮】，并清晰展示“上一次成功更新时间”。
- **[页面] 批量解析智能生成工作台**
  - **功能要求**: 
    - **智能题型与名师匹配引擎**：勾选导入的新题后，系统自动识别题目所属的细分子类，并结合设定的网络评价权重，**自动推荐并勾选**最擅长该题型的 2-3 位名师 Skill。
    - 允许管理员在点击“批量生成”前，**手动干预/修改**勾选的老师名单。后台并发调用模型填入解析。

### 📈 侧栏 2: 数据与 Token 计费看板
- **[页面] 全局业务大盘**
- **[页面] 契约资金盘健康度监控**
- **[页面] AI Token 消耗仪表盘**

### 🛡️ 侧栏 3: UGC 与社区治理 (安全底线)
- **[页面] 帖子/评论机审过滤池**
- **[页面] 涉黑灰产影子封禁中心**
