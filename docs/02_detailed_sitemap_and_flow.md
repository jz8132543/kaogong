# 全站 Sitemap 与流转蓝图 (C端 + B端后台)

## 📱 C端 (备考用户 App/小程序)
采用移动端经典的底部 4 个 Tab 导航。

### Tab 1: 首页与学习 (Home & Practice)
- **[一级] 学习主页 (`/`)**：新用户摸底、今日推荐任务、金刚区分类入口。
- **[二级] 题库分类列表页 (`/category`)**：深度细化到子知识点（如：空间重构），支持按特定名师的技巧（如老王代入法）进行归类筛选。
- **[二级] 刷题详情页 (`/practice`)**：多模态图文题干展示、**正向计时器**记录思考时间、答题卡底部抽屉弹窗、交卷二次确认弹窗。
- **[二级] 题目解析与 AI 互动页 (`/analysis`)**：多位名师流派解析 Tab 切换、底部 AI 苏格拉底式追问框（扣除平台点数）。

### Tab 2: 学习数据看板 (Dashboard)
- **[一级] 数据主页 (`/dashboard`)**：年度学习热力图（点击查单日详情）、动态技巧掌握度雷达图。

### Tab 3: 督学社群 (Community)
- **[一级] 社群大厅 (`/community`)**：契约群推荐列表、高赞攻略瀑布流。
- **[二级] 契约督学群详情 (`/pledge-detail`)**：打卡日历、总奖金池，加入时拉起收银台弹窗。
- **[二级] 帖子详情页 (`/post`)**：图文展示、底部评论抽屉弹窗。

### Tab 4: 个人中心与商业化 (Profile)
- **[一级] 我的主页 (`/profile`)**：用户状态、零钱与 AI 点数余额。
- **[二级] 钱包与充值中心 (`/wallet`)**：提现流转、AI 点数充值包。

## 💻 B端 (平台管理员 / 运营后台)
采用侧边栏导航 (Side Navigation)。

### 侧栏 1: 题库与大模型资产
- **题库编辑大厅**：无论处于识别期还是入库后，管理员随时享有修改题干、选项、裁剪图片的**绝对编辑权**。
- **多模态 OCR 工作台**：拖拽 PDF，提取文字或 OCR 图片，自动框选保留几何/统计图。
- **AI 接口配置与模型嗅探中心**：配置 Base URL 与 Token。系统**自动嗅探并多选**可用模型。
- **名师 Skill 配置池**：除了手动输入，**支持从 Github URL 或文件导入**，提供【更新】按钮与上次更新时间展示。
- **批量解析生成工作台**：系统根据新题的细分题型，**智能勾选推荐 2-3 位名师**（允许人工覆盖），并发调用模型批量填入解析。

### 侧栏 2: 数据与计费看板
- **全局业务大盘**：DAU、契约群规模。
- **契约资金健康度**：监控沉淀押金与净负债。
- **AI Token 消耗仪表盘**：折线图监控大模型成本，以及**用户点数消耗排行榜**。

### 侧栏 3: UGC 社区治理
- **审核与过滤池**：处理被敏感词拦截的贴文。
- **涉黑灰产惩戒中心**：对竞品引流号执行**影子封禁 (Shadowban)**。
