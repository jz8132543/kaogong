# 全景多角色使用流程与体验细节

## 👨‍🎓 角色一：备考学员 (C端核心用户)

### 1. 冷启动体验
- **痛点**：目标未定或中途变更（国考转省考）。
- **Wow Feature**：**AI 极速摸底测试**。新注册用户做一套定制 20 题，立即生成初始能力雷达图，瞬间建立产品的专业信任感。

### 2. 刷题与解析流转
- **痛点**：传统倒计时焦虑、被打断进度丢失、单一解析看不懂。
- **体验设计**：改用**正向计时器**；引入**单题实时缓存防中断机制**。
- **Wow Feature**：
  - **名师流派无缝切换**：一道题平行提供 A老师(画图流)、B老师(公式流) 解析，用户可自选最爱。
  - **AI 追问付费闭环**：对某条解析仍不懂，可在下方直接追问，按次扣减平台点数（对应后台 API 成本的转移与盈利）。

### 3. 数据正向反馈
- **Wow Feature**：
  - 学习热力图与雷达图的动态生长动画。
  - 每周日晚自动生成的**备考周报总结**（极易分享朋友圈产生社交裂变）。

### 4. 契约社群博弈
- **体验设计**：处理请假（利用虚拟币换补签卡）与极度严苛的 00:00 时区结算规则。
- **Wow Feature**：云自习室同侪压力（在线学习人数与状态同步）。

## 👨‍💻 角色二：系统管理员 (B端运营)

### 1. 自动化录题与随时编排
- **Wow Feature**：**多模态 OCR 导题系统**。对于文字 PDF 直接精确抽取，纯图片 PDF 进行 OCR。智能保留题干内的原版插图。且赋予管理员在生命周期任意节点的随时修改权。

### 2. 大模型与 Token 资产运作 (核心壁垒)
- **Wow Feature**：
  - **智能题型判定与名师自动匹配**：导入新题时，不仅能选，系统还会主动“根据网络评价和题型权重”自动勾选最适合的 2-3 名老师进行解析生成。
  - **Skill 配置源的动态更新**：直接链接至 GitHub 等外部 URL 拉取名师 Prompt 配置，一键同步最新教研成果。

### 3. UGC 治理与风控
- **Wow Feature**：面对社区里潜伏的卖课黑产，直接启用**影子封禁 (Shadowban)** 技术。违规账号自己能看到发帖，但对真实用户群体彻底隐身，实现零冲突维稳。
